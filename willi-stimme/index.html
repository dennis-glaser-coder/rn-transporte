Die neue Piper/Thorsten-Stimme wird lokal im Browser berechnet. Beim ersten Start wird ein großes Sprachmodell heruntergeladen; auf manchen Handys kann dies lange dauern oder fehlschlagen. Die Schaltfläche „Browserstimme anhören“ nutzt alternativ die Stimmen deines Geräts. Diese Hörprobe nutzt keine ElevenLabs-API und keine kostenpflichtige KI. Manche Browser verwenden für die Spracherkennung einen externen Dienst – deshalb hier bitte keine echten Kundendaten diktieren. Die Stimmqualität hängt von deinem Gerät und Browser ab; eine bestimmte männliche Stimme kann ich nicht garantieren.
